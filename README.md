Construyo y pongo en producción sistemas completos: desde el modelo de datos y la API hasta la interfaz web y el pipeline de entrega.

## Stack

**Aplicaciones:** TypeScript · Node.js · NestJS · React · Next.js · PHP · Python  
**Datos:** PostgreSQL · MySQL · Redis · RabbitMQ  
**Infraestructura:** Docker · Kubernetes · Terraform · GCP · AWS · GitHub Actions

## Proyectos

- **Frota360**: sistema de gestión de alquiler de vehículos, en uso por una empresa de alquiler, con más de 30 conductores activos y 50 vehículos, con cobro semanal automático, conciliación de pagos por un auditor, control de acceso por rol, 2FA e informes (NestJS, Next.js, PostgreSQL, Redis, S3)
- [**vitrine-zap**](https://vitrine-zap-dun.vercel.app): catálogo multitienda con pedido listo para enviar por WhatsApp y panel para el comerciante (Next.js, TypeScript)
- [**cv-generator**](https://cv-generator-liart.vercel.app): generador de currículos con IA, PWA offline-first
- [**ssh_dev_tunnel**](https://github.com/igor-rl/ssh_dev_tunnel): CLI para túneles SSH inversos con gestor de contraseñas (Python)

## Cómo trabajo

- Reglas de dominio explícitas y probadas
- Seguridad por defecto: permisos por rol, auditoría y autenticación robusta
- Consistencia garantizada por la base de datos, no solo por la aplicación
- Entornos reproducibles, entrega continua y sistemas que otro equipo puede mantener
